vdB Courses is a private reader for a personal library of interactive study material — mathematics, science, medicine, pool chemistry and electronics — written from first principles, with diagrams, checkpoints and a review queue.

Getting started

On first launch the app asks who the device belongs to. Choosing the student profile limits the library to the courses meant for that reader; the full profile shows everything. Tap a course to see its lessons, then Start course to read it.

Everything works offline

Courses are bundled inside the app. There is no sign-in, no account, and no network needed. Progress is saved automatically as you read.

Common questions

The text is too small. Use the A− and A+ buttons at the top right while reading. The setting is remembered.

My progress disappeared. Progress is stored on the device only, so deleting and reinstalling the app clears it.

The fonts look different. The courses use web fonts that load when online. Offline, the system typeface is substituted — everything still works.

How do I leave a student profile? Open Settings from the library and press and hold the profile row for about two seconds.
